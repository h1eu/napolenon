# Napoleon — plan triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tạo repo `napoleon`: thư mục `.claude/` đóng gói (lệnh, skill, agent, tools Python, hooks, templates) + `install.sh` + test, copy vào dự án Claude Code bất kỳ là dùng được.

**Architecture:** Tầng dự án bổ sung cho superpowers. Một vòng lặp chính, một agent `verifier`. Trạng thái và số liệu đi qua tools Python stdlib; chỉ dẫn dự án do `/start-build` sinh vào `.claude/instructions/`, trạng thái vào `docs/napoleon/`.

**Tech Stack:** Markdown (Claude Code commands/skills/agents), Python 3 stdlib (sqlite3, json, re, pathlib, unittest), bash, codegraph MCP, context7 MCP.

**Spec:** `docs/superpowers/specs/2026-11-08-napoleon-design.md`

**Lưu ý:** Người dùng yêu cầu **không `git init`, không commit** trong lần triển khai này. Bỏ mọi bước commit. Chạy test bằng `tests/run.sh`.

## Global Constraints

- Python 3 stdlib, không dependency ngoài. Node không dùng trong `.claude/`.
- Toàn bộ nội dung markdown tiếng Việt; tên file/lệnh/tool tiếng Anh.
- `CLAUDE.md` lõi ≤ 100 dòng. Mô tả agent/skill ≤ 3 dòng trong frontmatter.
- Hook luôn `exit 0`.
- File sinh bởi `/setup-agents` bắt đầu bằng `<!-- napoleon:generated -->`.
- Tool chạy từ thư mục gốc dự án; đường dẫn mặc định: `docs/napoleon/state.json`, `.claude/instructions/rules.json`, `.claude/instructions/toolchain.json`, `.codegraph/codegraph.db`, `reports/roadmap.html`. Mọi tool nhận `--root <dir>` để test.
- `state.py` ghi atomic (ghi `.tmp` rồi `os.replace`).

## Review Focus

1. `state.py` với tên feature chứa khoảng trắng hoặc ký tự lạ → phải chấp nhận hoặc từ chối rõ, không ghi file hỏng. (Task 2 test `test_feature_name_with_spaces`.)
2. `conform.py` với glob không khớp file nào → in `0 file quét`, exit 0, không im lặng. (Task 3 `test_no_files_matched`.)
3. `audit.py` khi DB codegraph có schema lạ → chuyển `scan` và in dòng `source: scan`, không exception. (Task 4 `test_unknown_schema_falls_back_to_scan`.)
4. `report.py` khi không phải git repo → mục commit hiện "không có dữ liệu", vẫn sinh HTML. (Task 5 `test_no_git_repo`.)
5. `check.sh` khi lệnh format trả lỗi → in lỗi ra stdout nhưng vẫn exit 0. (Task 6 `test_check_format_fails_still_exit0`.)
